# Coffee Shop Sales Analysis & Interactive Excel Dashboard

An end-to-end **Coffee Shop Sales Analysis project using Microsoft Excel**, focused on transforming raw transaction data into meaningful business insights through data cleaning, calculated fields, Pivot Tables, and an interactive dashboard.

## Project Overview

This project analyzes coffee shop transaction data to understand **sales performance, product demand, customer purchasing patterns, store performance, and time-based sales trends**.

The dataset contains approximately **149,000+ transaction records** with information including transaction date and time, store location, product category, product type, quantity, unit price, and total sales amount.

## Key Features

* Data cleaning and preparation using Excel
* Creation of calculated fields such as:

  * Total Amount
  * Month Name
  * Day Name
  * Hour
  * Start of Month
  * Month Index
* Pivot Tables for multidimensional sales analysis
* Time-based analysis of sales and transaction volume
* Product category and product-type performance analysis
* Store/location-wise performance analysis
* Day-of-week and hourly transaction analysis
* Interactive Excel dashboard for business reporting
* KPI-driven visualization for quick decision-making

## Analysis Performed

The project explores questions such as:

* Which products and categories generate the highest sales?
* Which store locations perform better?
* Which days of the week have the highest transaction volume?
* What are the busiest hours?
* How does sales performance change month over month?
* Which products contribute most to overall revenue?
* What purchasing patterns can be identified from transaction data?

## Objective

The primary objective of this project is to demonstrate how **raw transactional data can be transformed into an interactive business intelligence dashboard using Excel**, enabling stakeholders to identify sales trends, understand product performance, and make data-driven decisions.
